Dalek gog CLI

Dalek gog CLI is a private, single-user integration between a personal OpenClaw assistant and Google Workspace services. It uses the open-source gog CLI on the user's own computer to access only the Google account and permissions the user authorizes.

It can read and work with Gmail, Calendar, Drive, Docs, Sheets and Contacts when the user requests those tasks. It is not a public service or a way for other people to connect their accounts.
