Privacy policy

Last updated: 29 September 2026.

Dalek gog CLI is a private integration for one user. It requests access to the user's Google account so the personal assistant can perform tasks that user asks for in Gmail, Calendar, Drive, Docs, Sheets and Contacts. Data is accessed only for those tasks, not for advertising or sale.

The OAuth client credentials and refresh token are stored on the user's own computer in protected local storage. Google data retrieved for a task can be included in the assistant's conversation and processed by the AI service configured for that assistant to produce an answer. The integration does not run a public application server or maintain a separate database of Google user data.

Access can be revoked at any time in the Google Account's third-party connections settings. The local OAuth token and conversation data can be removed by the computer owner. Google data is not sold or shared for advertising.

This site is hosted by GitHub Pages, which may process standard web request data when the page is visited. For questions about this integration, use the support email shown on its Google consent screen.
